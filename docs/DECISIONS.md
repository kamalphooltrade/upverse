## D-001 · 18 ก.ย. 2569 · เปิดรางส่งคำสั่งผ่าน Webull API ครั้งแรก (ไม้เสนอ: ขาย AXON 0.00639 ≈ $2.88)
**บริบท:** ต้นถาม "api สั่งขายให้เลยได้ไหม" หลังยืนยัน thesis AXON "ออก" · ประตู §14.3 ยังไม่ผ่าน (environment uat · kill switch ปิด 2 ชั้น · whitelist ว่าง)
**ข้อเท็จจริงที่ได้วันนี้:** preview บน prod ผ่าน (body TH v3 `new_orders[]` · เศษหุ้น 0.00639 รับได้ · `estimated_cost $2.88 · estimated_transaction_fee $0.02`) · body แบบ US เดิมถูกปฏิเสธ "Orders can not be empty." · Webull TH มี UAT host + บัญชีทดสอบร่วม (เพิ่งรู้ — v0.1 เข้าใจผิดว่าไม่มี)
**ผลทุบ lucifer (สรุป):** "ไม่ทิ้ง แต่ห้ามยิงตามที่เสนอ" — (1) แยก 2 งานที่ถูกมัดรวม: ออกจาก AXON (ตัดสินแล้ว ขายมือได้วันนี้) กับ เปิดราง API (โปรเจกต์ทดสอบของตัวเอง) (2) โค้ดยังไม่พร้อมยิงจริง: ไม่มี poll ผลหลังส่ง · DB เขียนหลังยิง · timeout 15 วิ + client_order_id มี timestamp → กดซ้ำ = ส่งซ้ำ (แก้ id คงที่ + log ก่อนยิงแล้ว 18 ก.ย. · poll/reconcile ยังไม่ทำ) · confirm ไม่บังคับ preview · กฎ position ใช้ ledger ไม่ใช่ snapshot (3) "$2.88 เล็ก" ห้ามใช้เป็นเหตุผลข้ามประตูที่เขียนไว้เอง — บรรทัดฐานคือของแพง (4) ไม้แรกต้องเป็น SELL · MARKET · ช่วงตลาดเปิด · whitelist 1 ตัว · เพดาน ≤ $10 · ต้นนั่งดู · ปิด kill switch คืนทันที
**ทางเลือก:** (A) ขาย AXON ทางรางส่งมือวันนี้ + ทำราง API เป็นโปรเจกต์แยก (UAT จริงก่อน) · (B) fast-track: แก้โค้ด 5 จุด → preview → ทดสอบ kill switch + คำสั่งที่ fill ไม่ได้/cancel → ไม้ AXON เป็นไม้ API แรกก่อนตั๋วหมดอายุ 23 ก.ย. · (C) ไม่เปิดราง API จนกว่าครบเกณฑ์เดิม 30 วัน/10 ตั๋ว
**คำแนะนำ upverse-advisor:** A (AXON ออกวันนี้ · เก็บ "ไม้ SELL เล็ก" ตัวถัดไปหรือ UAT เป็นสนามทดสอบ) — เหตุผล: ไม่มีอะไรได้จากการรอ 2–4 วันบน $2.88 และท่อพิสูจน์ได้ 90% บน UAT โดยเสี่ยง $0
**คำตัดสิน:** _รอต้น (+ michael)_ · **สถานะ:** เปิด

## 1. ระบบดีไซน์ (Design System)

### 1.1 บุคลิกของหน้าจอ
"**แผงควบคุมที่สงบ**" — ข้อมูลหนาแน่นแต่ไม่ตะโกน · ตัวเลขเป็นพระเอก · สีมีความหมายเสมอ (ไม่ตกแต่ง) · ทุกตัวเลขบอกที่มา · ปุ่มที่ "ทำให้เงินขยับ" ต้องดูต่างจากปุ่มอื่นและอยู่ใต้นิ้วโป้ง

ผลจาก `ui-ux-pro-max` เสนอ Minimalism + Inter + น้ำเงิน/ส้ม พื้นสว่างเป็นค่าเริ่มต้น และเตือน "อย่ามืดเป็นค่าเริ่มต้น" — **ตัดสิน:** ใช้โครง Minimalism (ลำดับชั้นชัด · เอฟเฟกต์น้อย) แต่ **ธีมตามเครื่อง** (มืด/สว่างเท่ากัน ไม่บังคับ) เพราะต้นใช้ตอนกลางคืน และ **ไม่ใช้สีส้มเป็น accent** (บ้านนี้เลิกใช้ส้มแล้ว) — ใช้เขียวเป็น accent เดียวตามที่ต้นเคยรับ

### 1.3 ตัวอักษร
- **ไทย:** IBM Plex Sans Thai (400/500/600/700) · **ละติน:** IBM Plex Sans · **ตัวเลข:** IBM Plex Mono `font-variant-numeric: tabular-nums` (ตัวเลขเรียงตรงในตาราง) — Google Fonts มีครบ (ตรวจแล้ว 200)
- ขนาดฐาน **17.5px** · ระยะบรรทัดไทย **1.8** · หัวการ์ด 15px/600 ตัวพิมพ์ปกติ (ไม่ใช้ตัวพิมพ์ใหญ่ทั้งคำ) · ตัวเลขใหญ่ (มูลค่าพอร์ต) 34px mono/600 · ป้ายเล็กสุด 13px (ที่มา/เวลา) ห้ามเล็กกว่านี้
- **ทางเลือกให้ต้นเลือก (ไม่เดา):** (A) Plex ทั้งชุดตามเดิม · (B) Prompt (ไทย) + Plex Mono ตัวเลข — เข้ากับสไลด์ B2B ที่ต้นชอบ · (C) Sukhumvit Set (ระบบ) + Plex Mono — mockup ทำเป็น A และมีสวิตช์ลอง B ในหน้าตั้งค่า

### 1.4 ระยะ · รูปทรง · เอฟเฟกต์
- กริด 4px · ขอบหน้า 16px (มือถือ) / 24px (เดสก์ท็อป) · การ์ดมุมโค้ง 16px · ปุ่ม 12px · ป้าย 999px
- Glass: `backdrop-filter: blur(14px)` เฉพาะการ์ดชั้นบน (≤ 3 ชั้นซ้อนต่อหน้า — บนมือถือเก่าจะกระตุก) · เงานุ่ม 1 ระดับ
- การเคลื่อนไหว: เปลี่ยนสี/ยกการ์ด 200ms · ตัวเลขราคาเปลี่ยน = กระพริบพื้นเบา ๆ 400ms สีกำไร/ขาดทุน · เคารพ `prefers-reduced-motion`
- ไอคอน: Lucide (SVG) เท่านั้น · ไม่ใช้อีโมจิเป็นไอคอนควบคุม (อีโมจิใช้ได้ในป้าย 🤖 เพราะเป็นความหมาย ไม่ใช่ปุ่ม)

### 1.5 ส่วนประกอบ (Components)
| ชื่อ | กติกา |
|---|---|
| **EnvBadge** | มุมบนขวาทุกหน้า: `UAT` น้ำเงิน / `PROD` แดงเต็มแถบ (ไม่ใช่แค่ป้าย — แถบบนกว้างเต็มจอ) / `PAPER` เทา / `ไม่ได้เชื่อม` เตือน |
| **SourceTag** | ใต้ทุกตัวเลขสำคัญ: `Webull · 21:41:12` หรือ `สำรอง (Finnhub) · ดีเลย์ 15 นาที` · แตะแล้วขยาย |
| **StaleBanner** | แถบเหลืองเมื่อ quote ค้าง > 15 วิ (ตลาดเปิด) หรือข้อมูลของคืนก่อน |
| **MoneyPair** | USD ใหญ่ · THB เล็กใต้ · อัตราแลกเปลี่ยน+ที่มาใน tooltip |
| **DeltaChip** | `▲ +1.24%` / `▼ −0.80%` สี+เครื่องหมาย+ลูกศร |
| **ScoreRing** | วงคะแนน 0–100 + ตัวเลขกลาง · แตะเห็นองค์ประกอบ (score_parts) |
| **StockCard** (สแกน) | อันดับ · โลโก้ตัวอักษร · สัญลักษณ์/ชื่อ · ราคา+Delta · 3 ตัวชี้วัด · "ทำไม" 2 บรรทัด (ขยายได้) · ปุ่ม: ดู · ★ · ขอ thesis |
| **RiskCheckList** | รายการ ✅/⚠️/⛔ พร้อมตัวเลขจริง (เช่น "ไม้นี้ = 0.8% ของพอร์ต ≤ 1%") |
| **ConfirmPhrase** | ช่องพิมพ์ประโยคยืนยันที่ระบบสร้าง · ปุ่มเปิดใช้เมื่อตรงทุกตัวอักษร · แสดง environment ในปุ่ม ("ส่ง UAT") |
| **ManualRailCard** | รายละเอียดคำสั่งแบบก๊อปได้ทีละช่อง + ปุ่ม "เปิดแอป Webull" + ฟอร์ม "ทำแล้ว ราคา/จำนวน" |
| **EmptyState** | ไอคอน · 1 ประโยคบอกสถานการณ์ · 1 ปุ่มขั้นถัดไป |
| **BottomBar** (มือถือ) | 5 ปุ่ม 56px สูง · ปุ่มกลาง "ตั๋ว" มีจุดแดงเมื่อมีตั๋วรอ · ซ่อนเมื่อคีย์บอร์ดขึ้น |
| **SideNav** (≥1024px) | รายการเดียวกับ BottomBar + ส่วนขยาย (watchlist · journal · เป้า · ตั้งค่า) |
| **DataTable → CardList** | ≥768px ตาราง · <768px แปลงเป็นการ์ดแถวละ 2 บรรทัด (สัญลักษณ์/มูลค่า · น้ำหนัก/P&L) |
| **Chart** | ตาม `dataviz`: แกนเดียว · เส้น 2px · crosshair+tooltip · ตารางสำรอง (ปุ่ม "ดูเป็นตาราง") · ไม่ใช้ spline |

### 1.6 การเข้าถึงและมือถือ (เช็กลิสต์ก่อนส่ง)
- [ ] ทุกจุดแตะ ≥ 44×44px · ระยะห่างปุ่ม ≥ 8px
- [ ] คอนทราสต์ตัวหนังสือ ≥ 4.5:1 ทั้งสองธีม (วัดในเบราว์เซอร์จริง ไม่ใช่คิดเอา)
- [ ] ไม่มีข้อมูลที่สื่อด้วยสีอย่างเดียว (กำไร/ขาดทุน · UAT/PROD · ✅/⛔ มีไอคอน+ข้อความ)
- [ ] โฟกัสคีย์บอร์ดเห็นชัด (วงเขียว 2px) · ลำดับแท็บสมเหตุสมผล
- [ ] ไม่มี horizontal scroll ที่ 375px · กราฟยืดเต็มกว้าง · ตารางกลายเป็นการ์ด
- [ ] ปุ่ม "ยืนยัน" ไม่อยู่บนสุดของจอ (กันกดพลาดตอนเลื่อน) และมี safe-area ล่างสำหรับ iPhone
- [ ] ทุกหน้ามี 4 สถานะ: ว่าง · โหลด · ผิดพลาด · ค้าง/สำรอง
- [ ] ทดสอบที่ 375 · 768 · 1024 · 1440 · โหมดมืด/สว่าง · ขยายตัวอักษร 125%
- [ ] PWA: `manifest` + ไอคอน + เปิดแบบ standalone · ใช้ offline ได้เฉพาะหน้าที่แคช (พอร์ตล่าสุด · journal)

## 3. หน้าจอทีละหน้า (โครง + สถานะ + สิ่งที่ห้ามพลาด)

### 3.1 ล็อกอิน
อีเมล → OTP/ลิงก์ · ข้อความ "ใช้ส่วนตัว · ไม่ใช่คำแนะนำจากผู้มีใบอนุญาต" · ไม่มีปุ่มสมัคร (allow-list)

### 3.2 หน้าหลัก (Home)
- บนสุด: ทักทายสั้น + สถานะตลาด (`เปิดใน 2 ชม. 12 น. · 20:30 ICT`) + EnvBadge
- การ์ดพอร์ต: มูลค่า USD/THB · DeltaChip วัน · แถบความคืบหน้าสู่เป้า (% + "ต้องได้ x%/ปี") · SourceTag
- การ์ดตั๋วรอ: จำนวน + ตั๋วแรก (สัญลักษณ์ · ทาง · มูลค่า · หมดอายุใน) → แตะไปหน้ายืนยัน
- การ์ดสแกน: "เข้าใหม่คืนนี้" 3 ตัว (โมเดล · คะแนน) → สแกน
- การ์ดสัปดาห์นี้: วันงบของหุ้นที่ถือ/ตาม · แจ้งเตือนที่ยิงเมื่อคืน
- การ์ด journal ค้าง (ถ้ามี) สีเตือน
- **ว่าง:** "ยังไม่มีพอร์ต — เชื่อม Webull หรือบันทึกรายการแรก" ปุ่ม 2 ทาง

### 3.3 พอร์ต
- สวิตช์: รวมทุกบัญชี | Webull ••••1234 (UAT) | Paper
- MoneyPair ใหญ่ + DeltaChip วัน + P&L รวม (แยก "หุ้น" / "ค่าเงิน" 2 บรรทัด) + เงินสด/กระสุน DCA
- กราฟมูลค่า 90 วัน (เส้นเดียว · ไม่ spline · tooltip วัน/มูลค่า/เติมเงิน)
- สัดส่วน: แถบซ้อนแนวนอน แกน/ดาวเทียม/รายได้/เงินสด เทียบเป้า (สองแถบ: จริง vs เป้า) — ไม่ใช้โดนัทเป็นหลัก (อ่านยากบนมือถือ) · โดนัทเป็นทางเลือก
- รายการถือครอง (CardList บนมือถือ): สัญลักษณ์ · จำนวน (6 ทศนิยม) · มูลค่า · น้ำหนัก% · P&L · ป้ายกฎ (⚠️ ใกล้เพดาน) · วันงบถ้าใน 14 วัน · แตะ → หุ้น
- FAB "+ บันทึกรายการ" (Paper) → ชีทล่าง: ชนิด · สัญลักษณ์ · จำนวน · ราคา · ค่าธรรมเนียม · FX rate · วันเวลา · โน้ต
- **ค้าง:** StaleBanner + ตัวเลขเป็นสีรอง · **ไม่ได้เชื่อม:** การ์ด "เชื่อม Webull" แทนสวิตช์

### 3.4 สแกน
- แท็บเลื่อนแนวนอน: M1 กลับตัว+วอลุ่ม · M2 ดาวรุ่ง VI · M3 ของถูกมีเหตุผล · M4 ผู้นำแนวโน้ม · M5 เครื่องจ่ายเงิน · ✦ ซ้ำหลายโมเดล · ⛔ หลีกเลี่ยง
- หัว: `รัน 05:31 ICT · จักรวาล 503 · ผ่าน 37 · v1.0` + ปุ่ม "รอบก่อน" + "ความแม่น"
- StockCard ×10 (ดู §1.5) · การ์ดขยายเห็น score_parts + ตัวเลขทั้งหมด
- ท้าย: "ตัดออกเพราะข้อมูลไม่ครบ (12)" ขยายได้ · "ดูรายการเต็มที่ผ่านตะแกรง (37)"
- หน้า "ความแม่น": ตารางโมเดล × horizon (5/20/60 วัน) · hit-rate · ผลเฉลี่ย vs SPY · จำนวนรอบ · กราฟเส้นต่อโมเดล (แกนเดียว · 4 สี categorical)
- **ล้ม/เก่า:** หัวเป็นสีเตือน "ข้อมูลของ 16 ก.ย." + เหตุผล

### 3.5 หุ้น (Instrument)
- หัว: สัญลักษณ์ · ชื่อ · sector · ราคา+Delta · SourceTag · ป้าย: ถือ 0.52 หุ้น (3.1%) · M4 #3 · ★
- กราฟแท่งเทียน 1Y (สลับ 3M/1W) + EMA20/SMA50/SMA200 สลับเปิดปิด · แผงปริมาณ · แผง RSI14 · crosshair · "ดูเป็นตาราง"
- ตัวเลขพื้นฐาน: กริด 2 คอลัมน์ (มือถือ) / 4 (เดสก์ท็อป) · แต่ละช่องมี SourceTag ย่อ (`EDGAR FY2025`) · ช่องไม่มีข้อมูล = "—" + "ไม่มีข้อมูล"
- Thesis: ป้ายสถานะ (🤖 draft · ✅ ยืนยัน · ⚠️ เก่า) · 7 หัวข้อพับได้ · ฉากทัศน์ bear/base/bull เป็นตาราง · ปุ่ม "ยืนยัน" (owner) / "ขอใหม่"
- ปุ่มล่างติดจอ: ★ Watchlist · สร้างตั๋ว · บันทึก journal

### 3.6 Watchlist
- รายการ: สัญลักษณ์ · ราคา · ระยะจากโซนเข้า (แถบเล็ก: ต่ำกว่า/ในโซน/สูงกว่า) · วันงบ · โมเดลที่มา · ปุ่มแจ้งเตือน
- ชีทเพิ่ม: สัญลักษณ์ · เหตุผล · โซน · ตัดขาดทุน · แจ้งเตือน (เข้าโซน/หลุดระดับ/วอลุ่ม/วันงบ) · ช่องทาง LINE · ชั่วโมงเงียบ

### 3.7 ตั๋ว (รายการ + รายละเอียด) — หน้าที่สำคัญที่สุด
- รายการ: กลุ่มตามสถานะ · การ์ด: ทาง+สัญลักษณ์ · มูลค่า USD/THB · ผลตรวจย่อ (✅3 ⚠️1 ⛔0) · หมดอายุใน · ผู้เสนอ (🤖 agent / ต้น)
- รายละเอียด (เลื่อนจากบนลงล่าง — ลำดับตั้งใจให้ "อ่านก่อนกด"):
  1. หัว: ทาง · สัญลักษณ์ · EnvBadge ใหญ่ ("จะส่งไปที่ UAT — ไม่ใช่เงินจริง")
  2. ตัวเลขคำสั่ง: จำนวน/มูลค่า · ชนิด · ราคา limit · ราคาตลาดตอนนี้ (สด + SourceTag) · ตัดขาดทุน · เป้า · R:R · % พอร์ตหลังทำ
  3. RiskCheckList (ตัวเลขจริงทุกข้อ)
  4. เหตุผล 3 บรรทัด + thesis ที่อ้าง (ลิงก์) + **ทางเลือกที่ 0** + **อะไรจะทำให้คิดผิด**
  5. Preview จากโบรกเกอร์ (ถ้ามี): มูลค่า · ค่าธรรมเนียม
  6. ConfirmPhrase + ปุ่ม "ยืนยันและส่ง UAT" (ปิดใช้จนพร้อม) — หรือ ManualRailCard ถ้าเป็นรางส่งมือ
  7. ปุ่มรอง: ปฏิเสธ (ต้องใส่เหตุผล → journal) · แก้ไข (สร้างเวอร์ชันใหม่ ตรวจใหม่)
- **หลังส่ง:** ไทม์ไลน์สถานะ (proposed → confirmed → sent → filled) + broker_order_id + ปุ่ม "บันทึก journal" เด้งอัตโนมัติเมื่อ filled

### 3.8 สมุดบันทึก (Journal)
- ฟอร์มสั้น (ทำเสร็จใน 60 วิ): การตัดสินใจ · อารมณ์ (ชิป 5 ตัว) · คาดหวังอะไร · ย้อนดูเมื่อ (30/90) · บทเรียน (ไม่บังคับตอนแรก)
- รายการ: การ์ดเวลา/สัญลักษณ์/อารมณ์/ผล (เติมทีหลัง) · ตัวกรองอารมณ์/แท็ก
- สรุปไตรมาส: ตัวเลข (จำนวน · สัดส่วนอารมณ์ · ผลเฉลี่ยตามอารมณ์) เป็นตาราง + 1 กราฟแท่งแนวนอน

### 3.9 เป้า/DCA
- ฟอร์มเป้า: ยอด THB · วันเป้า · เริ่ม · เติม/เดือน · วัน DCA · สัดส่วน
- ผลทันที: "ต้องได้ x%/ปี" ตัวใหญ่ + คำอธิบาย 1 บรรทัด + ปุ่มเลื่อน 2 ตัว (เติมเพิ่ม / ยืดเวลา) เห็นผลสด
- กราฟเส้นทาง 3 ฉากทัศน์ (ผู้ใช้กรอกผลตอบแทนสมมติเอง · ช่องว่างจนกว่าจะกรอก) + จุด "ตอนนี้"
- ปุ่ม "สร้างตั๋วชุด DCA เดือนนี้" → ตั๋วหลายใบ (ยืนยันทีละใบ)

### 3.10 ตั้งค่า
- **เชื่อม Webull:** wizard 3 ขั้น (กุญแจ → 2FA → ทดสอบ) · การ์ดสถานะ (เชื่อมแล้ว · ••••1234 · token หมด dd/mm · ตรวจล่าสุด) · ปุ่ม rotate/ตัด
- **Environment:** สวิตช์ UAT/PROD · PROD ต้องพิมพ์ "เปิดเงินจริง" + เตือนเต็มจอ · เฟส 1 ปิดใช้ + ข้อความ "ต้องผ่านประตูเฟส 2 (ดู SPEC §14.3)"
- **กฎความเสี่ยง:** ฟอร์มค่าตาม SPEC F1.3 · แสดง "เวอร์ชัน v3 · ใช้ตั้งแต่ 17 ก.ย." · ประวัติเวอร์ชัน
- **ผู้ให้ราคา:** ลำดับ (ลากเรียง) · สถานะสุขภาพ 24 ชม.
- **แจ้งเตือน:** LINE เปิด/ปิด · ชั่วโมงเงียบ · ซ่อนยอดในข้อความ
- **API token:** สร้าง (เลือก scope · **ไม่มี confirm ให้เลือก**) · แสดงเต็มครั้งเดียว · เพิกถอน
- **ธีม/ฟอนต์:** ตามเครื่อง/มืด/สว่าง · ฟอนต์ A/B/C · ขนาดตัวอักษร
- **Kill switch:** ปุ่มแดง "หยุดส่งคำสั่งทั้งหมด" + สถานะ env `TRADING_ENABLED`

## 6.1 ทิศทางที่ต้นเคาะแล้ว (17 ก.ย. 2569 ค่ำ) → v2 "gradient + ขอบโค้งมน + smooth"
ต้นสั่งผ่าน `/ui-ux-pro-max`: **"ออกแบบ UI ให้สวยงาม ด้วย tailwind+react style gradient เน้นให้ขอบโค้งมน smooth"** → ปิดทางเลือกข้อ 2 (สไตล์) และกำหนด stack ของหน้าจอ = **Tailwind + React** (แพตเทิร์นไฟล์เดียวผ่าน CDN ของบ้านนี้ · ตอน build จริงย้ายเข้า Next.js ได้ตรง ๆ) · ข้อ 1 (ฟอนต์) · 3 (แถบ/โดนัท) · 4 (ปุ่มกลาง) · 5 (ภาษา) ยังรอ

**ต้นแบบ v2:** `docs/design/mockup-v2-gradient.html` (React 18 + Tailwind CDN + Babel · 10 หน้า · ข้อมูลสมมติ) — ใช้แทน v1 เป็นฐานของการ build · v1 เก็บไว้เทียบ

| องค์ประกอบ | ตัดสินใจใน v2 (Tailwind class) |
|---|---|
| การ์ด | `rounded-3xl` (24px) + ขอบ gradient บาง 1px (`p-px bg-gradient-to-br from-white/80 … dark:from-white/15`) + พื้น `bg-white/85 dark:bg-slate-900/70 backdrop-blur-xl` + แสงเรือง gradient มุมขวาบนเฉพาะการ์ดพระเอก (`glow`) |
| ปุ่มหลัก | `rounded-2xl` · `bg-gradient-to-r from-emerald-700 to-teal-700` (สว่าง · ขาว 5.0:1) / `dark:from-emerald-400 dark:to-teal-300 dark:text-emerald-950` (มืด · ≥ 8:1) · `shadow-glow` · ยกตัว 0.5px ตอน hover 300ms |
| แท็บ/ชิป | `rounded-full` · แท็บที่เลือกใช้ gradient เดียวกับปุ่มหลัก |
| แถบล่างมือถือ | ลอย `fixed left-3 right-3 bottom-3 rounded-3xl` glass · ปุ่มสูง 60px · safe-area |
| พื้นหลัง | สว่าง: gradient อ่อน `#F3FAF6 → #F6F7F9 → #EEF6FB` · มืด: aurora 3 จุด (สลับ "เรียบ" ได้) |
| ตัวเลขเด่น | ตัวเลข "ต้องได้กี่ %/ปี" ใช้ gradient text (`bg-clip-text`) — ตัวเดียวในระบบ ตัวเลขเงินยังเป็นสีทึบเพื่อความชัด |
| ทุกอย่างที่แตะ | `min-h-[44px]` รวม toggle และปุ่มเล็ก (วัดแล้ว 0 ปุ่มต่ำกว่า 44px ทุกหน้า) |
| การเคลื่อนไหว | `transition-all duration-300 ease-out` · เคารพ `prefers-reduced-motion` |

**ผลวัดในเบราว์เซอร์จริง (v2 · 375px · หลังแก้):** ไม่มี horizontal scroll ทั้ง 10 หน้า · คอนทราสต์ตัวหนังสือต่ำสุด **6.29:1 (มืด)** และ **5.02:1 (สว่าง)** — ผ่าน AA ทั้งคู่ (วัดรวมพื้น gradient ของปุ่มด้วย) · ปุ่มต่ำกว่า 44px = 0 · เดสก์ท็อป 1440px = แถบข้าง + 3 คอลัมน์ · ไม่มี error ใน console

**ข้อสังเกตจากสกิล ui-ux-pro-max รอบสอง:** ยังเสนอ Minimalism/Inter/น้ำเงิน-ส้ม (ฐานข้อมูลของสกิลเวอร์ชันนี้มีแค่ `ui-reasoning.csv`) — ใช้เฉพาะเช็กลิสต์ (touch ≥ 44 · คอนทราสต์ · reduced-motion · 4 breakpoints) ส่วนสไตล์ยึดคำสั่งต้น

# UPVerse

แอปและ agent ที่ปรึกษาการลงทุนส่วนตัว (Personal Financial Advisor) สำหรับพอร์ตหุ้นสหรัฐผ่าน Webull ประเทศไทย — สแกนตลาด · วิเคราะห์พื้นฐานแนว VI · เทคนิคหาจังหวะ · ออปชันแบบจำกัดความเสี่ยง · โมเดลบริหารพอร์ต

- สมอง: agent `upverse-advisor` (Claude Code) — วิเคราะห์และเตรียม "ตั๋วคำสั่ง" ให้เจ้าของพอร์ตยืนยันเอง ไม่ส่งคำสั่งซื้อขายเอง
- Stack (แผน): Next.js App Router · Supabase · Vercel · Webull OpenAPI (region `th`, เริ่มที่ sandbox)
- สถานะ/งานค้าง: `PROGRESS.md` · กติกาโปรเจกต์: `CLAUDE.md`

> ไม่ใช่คำแนะนำการลงทุนจากผู้มีใบอนุญาต · ใช้เพื่อการศึกษาและประกอบการตัดสินใจส่วนตัวเท่านั้น
